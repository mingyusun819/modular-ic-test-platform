# MATLAB User Interface

Place the MATLAB App Designer app (`.mlapp`) and supporting MATLAB functions (`.m`) here.

## Planned responsibilities

- Select and connect to the platform's serial port.
- Configure supplies and stimulus settings.
- Start and stop tests.
- Display status, numeric measurements, and plots.
- Export collected data.

## Initial interface

Begin with a connection control, one numeric setting, an Apply button, and a measurement display. Keep communication and data parsing in reusable functions so they can also be exercised independently of the GUI.

The command protocol and GUI implementation have not been added yet. Record the MATLAB release and any required toolboxes here when development begins.
